# Damián Nogueira Portfolio

Personal portfolio created to present my frontend development work through real project case studies.

## Current status

The project is currently in its initial deployment stage as part of the FlyRank Front-end AI Engineering track.

The first public version is intentionally minimal and contains only my name. The portfolio content and project case studies will be added progressively.

## Stack

- Vite
- React
- TypeScript
- React Router
- Custom CSS

## Projects to be featured

- Skillentis
- VireonFit
- Food Store
- Lynkroam — currently in development

## Local development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

The portfolio will be deployed as a static site on Vercel.
